Conversor de Temperatura em Python

Projeto simples em Python que converte temperaturas entre Celsius e Fahrenheit através de um menu interativo no terminal.

Funcionalidades
- Conversão de Celsius para Fahrenheit
- Conversão de Fahrenheit para Celsius
- Menu interativo

Tecnologias
- Python 3

Objetivo
Projeto desenvolvido para praticar lógica de programação, funções e estruturas de controle em Python.
